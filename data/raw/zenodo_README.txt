This package contains the 311 links to the analyzed postmortems for a study on the adoption and implementation of experimentation in software startups. These links were obtained in August, 2019 at CBInsights through the link https://www.cbinsights.com/research/startup-failure-post-mortem/
For those that were considered software startups and had useful information to the study, it was identified, if possible, the startup country, start and closing date, length of the active period, and business domain.


The file postmortems.tsv contains the following columns:

ID: unique identifying incremental id starting with 1 and ending in 311.

Title: the title of the postmortem (website page).

Url: url as available in the original page.

Found Url: if the url was not accessible (e.g. dead link), a mirror of the page in a different website or the one found in WebArchive (https://web.archive.org/).

Company name: the startup name.

Url: a url that contains a description about the startup.

Other Url: other urls used to get demographics information about the startup.

Company description: the description of the startup.

Other sources: other sources considered.


Is software startup? (Answer 1)	
Is software startup? (Answer 2)	
Is software startup? (Answer 1 vs 2)	
Is software startup? (Answer 3)	
Is software startup? (FINAL): columns detailing the process of determining which startups were software startups. We employed three raters (Answers 1, 2, and 3). The first two analyzed all the startups independently, if they agree, their answer was final. Otherwise, another rater (Answer 3) analyzed. 

Founder personal statement?: column indicating if the statement was made by a founder or no. Examples of not founder personal statements are articles on the press regarding the end of a company.

Has useful information?: column indicating if the statement has something useful to investigate the adoption and implementation of experimentation in software startups.

Country: the country where the startup was located.

Start year: the year the startup launched, if available.
Closing year: the year the startup closed, if available.	
Length of active period: the length of the active period if mentioned in the postmortem, rounded to the closest integer. If less than one year, rounded to one year.
Calculated active period: the length of the active period calculated based on the start and closing year. 
Considered active period: the considered length of the active period. If the Length of active period is present, it was used. Otherwise, the Calculated active period.	

Business domain: the business domain where the startup operated.

Author name: the name of the author of the postmortem. If it is not attributed to a person, it is put among paranthesis.


INSTRUCTIONS:

To select the software startups used in the study, use a filter YES on the columns as below:

Is software startup? (FINAL), Founder personal statement?, and Has useful information?

With this filter, the number of analyzed startups is 106.
